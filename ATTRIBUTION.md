# Third-party assets

Code dependencies are listed by `Cargo.lock` and checked by `cargo deny check` (permissive
licences only). This file lists non-code assets bundled with Inbetween.

| Asset | Used for | Source | Licence |
|---|---|---|---|
| Roboto Regular (`crates/render-cpu/assets/Roboto-Regular.ttf`) | The app's user-interface font and the default caption font | Roboto v2.138, https://github.com/googlefonts/roboto | Apache-2.0 (`crates/render-cpu/assets/Roboto-LICENSE.txt`) |

The demo images in `demo/` are generated by `crates/testkit/src/demo.rs` and are not third-party.
